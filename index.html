1 · Understands your product

It learns your product before it tests it.

Your product, from the sources you already keep

Scribe reads your repository first: its framework, page objects, fixtures and the graph of how tests reach the code. The agent reads stories and test cases in Jira, Azure DevOps and Xray, pages in Confluence, specs through your search service, and the product knowledge your team writes once: business rules, roles, glossary and test data.

Set up once in forgeqe.yaml and .forgeqe/knowledge.

2 · Tests every way, at once

One run. Every check.

One run in a real browser checks every step for function, and every page for accessibility, speed and visual change, on several browsers and systems side by side.

Function, accessibility, speed and look, in the same run

Each step’s expected result is checked on the live page. Along the way ForgeQE records Core Web Vitals and browser errors, runs axe-core on every page it reaches, and compares each screen with its baseline.

3 · Assures its own AI

Passing tests aren’t enough.

A change can pass every test and still be wrong for your product. So ForgeQE checks the change, proves every claim with its own run, has a second agent judge the work, and holds every agent to explicit rules.

Any pull request, checked against what it should do

ForgeQE reviews a pull request against its work item and your repository, then runs only the tests the change can break.

Its own AI is tested too

Its key prompts have eval suites, and each run is compared with the last. In CI, a gate fails the build when generated test cases cover your domain’s risks below your bar, and the team is told.

  • $ forgeqe prompts evalevery prompt’s cases, compared with the last run
  • $ forgeqe eval domain --min 0.8domain coverage, judged; below 0.8 fails the build

History catches flaky tests and regressions

Every run joins the history. Flaky tests are found and can be quarantined, every defect is marked new, known or a regression, and a failing case runs again to confirm it reproduces before anyone is told.
