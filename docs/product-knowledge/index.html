Product knowledge

What ForgeQE's agents should know about your product, written once and used on every run: what it does, who uses it, the words your team uses, the rules it follows, the data to test with, and where it runs. Fill in the files below (or add your own .md or .txt files, in folders if you like) and commit them.

How the agents use it:

  • ForgeQE's agent sees the list of these files and reads the ones a request needs (planning tests, judging a test case, answering about the product).
  • Planning agents (exploratory charters, API scenarios) get the sections that match the story or scenario.
  • The browser agent gets the few sections that match the goal (at most knowledge.browser_max_chars, default 1500 characters, so runs stay cheap).

Sections are found by their headings, so give each topic its own ## heading. A file you have not changed since forgeqe init copied it is left out: the templates' examples never reach an agent.

Never put passwords, tokens, or personal data here: use logins and environment variables for those.
