Feature test prompts

One prompt for each ForgeQE feature, to check the agent end to end. Type each prompt in the ForgeQE terminal (forgeqe start), started in the test project's folder (for example playwright-csharp-pom-framework).

#Before you start

  • Replace the <…> placeholders with your own ids (a story, a pull request).
  • ⚠ marks prompts that change something outside ForgeQE: Azure DevOps, Teams, git, or the repository. Run those on test data only.
  • Some prompts need an earlier run. #2, #17, #27, and #28 depend on #1 or #9, so run them after it.
  • Don't use test case 2287 for the API + UI check. As written, its step 2 gets a 403 (POST /add_to_cart is not how that site adds to the cart), and it signs in to a personal account. Use #26 instead.

#Environments, desktop, mobile, and tool scope

These need an env.yaml with the apps named. The desktop prompts need Windows with a signed-in, unlocked desktop. The mobile prompts need an emulator or device with Appium (or Maestro), or TestMu credentials in .env.
